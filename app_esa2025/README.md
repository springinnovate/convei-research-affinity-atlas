# CONVEI Research Affinity Atlas (ESA 2025)

This directory contains the temporary materials for the **CONVEI Research Affinity Atlas** created for **ESA 2025**.  
The atlas was originally set up to provide structured, queryable information about conference participants and their research affinities.

**Current Status:**  
This system was intended as a short-term resource during the ESA 2025 preparation period.  
It is **no longer functioning**, **not maintained**, and should be considered **temporary and deprecated**.  
Do not rely on it for current or accurate participant information.

The contents remain here only for reference and historical context.
